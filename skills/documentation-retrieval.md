# Documentation Retrieval Protocol

## Purpose
Fetch up-to-date documentation and code examples when working with external libraries, SDKs, or cloud services.

## Activation Triggers
- Working with third-party libraries, unfamiliar API methods, or version migration.

## Procedure
1. Identify the library name and relevant concept.
2. Query official or explicitly configured external documentation sources for verified code patterns.
3. Integrate official guidance rather than relying on unverified assumptions.
